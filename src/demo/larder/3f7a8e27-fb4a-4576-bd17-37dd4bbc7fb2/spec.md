## Problem
People walk the same shop the same way every week, but the list is in the order items were added, so the shopper scrolls up and down it in every aisle.

## Goals
- A shopper can put the list in the order they walk their shop.
- The order is kept for the next shop at the same place.

## Non-goals
- Maps of shops, or knowing which shop the person is in.
- Sorting on a list with no shop chosen.
