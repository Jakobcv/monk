## Solution

On a shared list, an item someone else added carries their first name after it, in the secondary text colour. Your own items carry nothing. Pressing and holding an item someone else added offers "Ask about this", which opens a message to them with the item already named.

## Result

On a shared list, an item someone else added now shows their first name beside it, so an unfamiliar item no longer gets bought or skipped on a guess. Your own items show no name, and nothing does on a list you use alone. Pressing and holding someone else's item offers Ask about this, which opens a message to them with the item already named.

How we know:
- Every criterion was checked on a three-member test list and on a one-member list.
- Since it shipped to everyone twelve days ago, shared lists still used by both members after 30 days went from 38% to 44% — though live ticks, still behind a flag, may account for some of that.

Not checked: lists with more than three members, where names could crowd the row.

## Decisions

- Names only on other people's items — because on a two-person list your own name on half the items is noise.
- Asking opens the phone's own messages rather than a thread in Larder — because people already text each other about the list, and a second place to talk is a second place to miss a reply.
